# Project Evolution View · schema v0.1

Status: `ACTIVE_RESEARCH / PUBLIC_SAFE`  
Scope: a query/projection over `MOH_METAGRAPH` for versioned project events, decisions, branches, tests, deprecations and return paths. It does not establish another graph root or infer a single inevitable project narrative.

Nodes use `id`, `kind`, `date`, `status`, `provenance` and `rollback`. Edges use `from`, `relation`, `to`, `reason` and `scope`. Private archaeology is reduced to anonymous, non-content-bearing receipts; no chat text, owner data or hidden source corpus is exported.

Knowledge, project, chronology, lineage, evidence, horizon and access are views over one canonical metagraph. Any new node family, query policy or runtime implementation must be proposed, scoped and approved separately.
