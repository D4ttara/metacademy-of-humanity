# Project Evolution Graph · schema v0.1

Status: `ACTIVE_RESEARCH / PUBLIC_SAFE`  
Scope: versioned project events, decisions, branches, tests, deprecations and return paths. It does not infer a single inevitable project narrative.

Nodes use `id`, `kind`, `date`, `status`, `provenance` and `rollback`. Edges use `from`, `relation`, `to`, `reason` and `scope`. Private archaeology is reduced to anonymous, non-content-bearing receipts; no chat text, owner data or hidden source corpus is exported.

Only two core graphs are maintained in this pass: this evolution graph and the Knowledge Graph. Any future graph must be proposed, scoped and approved separately.
