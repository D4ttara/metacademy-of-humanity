# SA003 · Time / Relation Operators v0.1

All operators are `OWNER_APPROVED_ACTIVE_RESEARCH`. They are bounded design operators, not universal laws or `.META` activation.

| Operator | Purpose | Minimal falsifier / limit |
|---|---|---|
| `LOCAL_TIME != GLOBAL_TIME` | retain local clock contexts | a single clock fully orders all relevant events |
| `CLOCK_REQUIRES_ORDERING_POWER` | accept a clock only if it orders the target events | changing value leaves relevant events ambiguous |
| `STATE_COORDINATE != TEMPORAL_DIRECTION` | distinguish state from phase | coordinate plus no history is sufficient |
| `STATE + HISTORY_MARKER → TEMPORAL_ORDER` | use residue/lineage to restore phase | marker is inconsistent or unavailable |
| `INTERNAL_TIME_RATE MAY BE RELATIONAL` | compare rates through relations | rates are assumed absolute without translation |
| `CLOCK_FAILURE MAY SIGNAL REGIME_CHANGE` | treat clock failure as a diagnostic | failure is merely corrupted data |
| `HORIZON_HOLD IS ACTIVE` | preserve unresolved continuations | pause is encoded as null / nothing |
| `EVENT_ORDER CAN SURVIVE CLOCK_TRANSLATION` | keep partial causal order across clocks | translation reverses a proven dependency |
| `RECOVERY_REQUIRES_REMAINDER` | distinguish reconstruction from recovery | no residue/constraints remain |
| `OBSERVER_FRAME IS PART OF THE RECEIPT` | record observation context | frame is silently universalized |

Special passports: deep-research and metaphysical interpretations may be attached only as `METAPHYSICAL_CLAIM` or `WORKING_HYPOTHESIS`; no fixture elevates them to physical fact.
