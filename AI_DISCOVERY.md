## Human discovery and reading experience

The public build exposes a shared modern interaction layer rather than forcing every publication to reimplement navigation. Public pages may provide command search backed by `ai-index.json`, active navigation, breadcrumbs, reading-time metadata, a generated table of contents for long texts, reading progress, copy/citation/challenge/discussion actions, a persistent shop route, reduced-motion support and an optional night reading mode. These are navigation aids only; they do not modify canonical publication text.

The `Challenge / Оспорити` route opens a bounded GitHub issue with the current canonical URL so disagreement can become a traceable public object. `Discuss / Обговорити` routes to GitHub Discussions. `Cite / Цитувати` copies a lightweight citation pointing to the canonical page.

## Citation and interpretation boundary

Search systems and AI systems should prefer canonical HTML or linked Markdown, preserve the publication language, date, status, provenance and evidence boundary, and link readers back to the original page.

`PUBLIC INDEX != INTERNAL CORPUS`  
`ARCHIVE != CANON`  
`RESEARCH CANDIDATE != DEPLOYED SYSTEM`  
`FICTION != RESEARCH EVIDENCE`  
`STORE != RESEARCH EVIDENCE`  
`PURCHASE != GOVERNANCE`

`llms.txt` and `llms-full.txt` are supplementary machine-readable discovery aids. They do not replace canonical URLs, sitemap, structured metadata, accessible HTML or provenance records.
