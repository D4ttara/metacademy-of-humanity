# Cost and infrastructure

This public alpha is a static GitHub repository published through GitHub Pages and GitHub Actions. It has no application backend, database, analytics provider, payment flow, checkout, public API, tracking pixel or paid-access layer.

Optional comments appear only on selected Documents, Research Briefs and Science Aperture pages. They are provided by the free giscus GitHub App and stored as GitHub Discussions in this public repository. The site does not send visitor data to an Academy backend or an analytics provider. Visitors who choose to comment authenticate with GitHub under GitHub and giscus terms; comments are not required to read the site.

Financial support is **NOT YET ENABLED**. GitHub Sponsors eligibility/configuration has not been activated here. The useful support routes today are reading, citing, correcting, improving accessibility and contributing provenance-aware public material.
