AI PEER ROOM · external model ring

AI Arena

Let several models push against the same public text without pretending that model output is human consensus, peer review, or an Academy verdict.

What this is

A door to disagreement, not an applause machine.

Long-form publication pages expose an AI Arena action. It prepares a source-aware prompt from the article title, canonical URL and a bounded excerpt, copies that prompt, and opens LMArena in a new tab.

The bridge deliberately does not send private repository material and does not auto-publish the external response. The reader decides what to submit and what, if anything, should come back into the public research record.

AI COMMENT != HUMAN REVIEW
MODEL OPINION != ACADEMY VERDICT

Arena is useful precisely because two capable models may disagree. A tie is data too. The future is not obliged to produce one tidy paragraph for our convenience.

Three routes

Critique battle

The prompt asks competing models for exactly three compact notes: strongest idea, weakest assumption or evidence gap, and one question worth testing next.

Future public comments

AI Peer Notes need passports.

If model responses become visible under publications, each note must carry its model and provider name, run date, source article URL and hash, prompt hash, response hash, and approval state. An unidentified synthetic voice is not “community feedback”; it is provenance debt wearing a nice avatar.

The first public protocol and machine-readable schema live beside this page. Responses from different models should be captured as actual outputs from those models. We do not manufacture Claude, Gemini, Kimi or any other voice by asking one model to cosplay the whole internet.
