# Search + AI discovery hub

`/discover/` is the human-facing entry point for the public discovery layer.

Generated during verified publication builds:

- `/ai-index.json` — machine-readable public page inventory;
- `/llms-full.txt` — full canonical URL index for LLM-oriented retrieval;
- `/sitemap.xml` — canonical public HTML URL map.

Curated / stable surfaces:

- `/llms.txt` — selected high-signal corpus guide;
- `/feed.xml` — publication RSS;
- `/robots.txt` — crawler access policy;
- `/identity/` and `/identity.json` — canonical project/entity identity.

The generator enhances already-public HTML only. It does not promote private or source-only material into the public corpus.

`PUBLIC INDEX != INTERNAL CORPUS`
